# esp32-based-smart-distance-alarm
it is an esp32 based alaram systems that displays the distance of the object and the buzzer sounds when it goes under 5 cm.
The ESP32-based distance alarm system utilizes an ultrasonic sensor to measure the distance to a nearby object, such as a metal cup. A small OLED screen displays this measured distance in centimeters in real-time. When the object moves within a critical threshold (around 5 cm or less), the system triggers a buzzer that sounds a warning, which shifts to a continuous alarm tone as the object gets closer.
